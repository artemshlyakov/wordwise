# Wordwise

Личный словарь для изучения английского через чтение. Приложение работает в браузере без установки, сборки и регистрации.

## Запуск

Открой `index.html` в современном браузере. Книги, главы и карточки сохраняются локально в браузере на этом устройстве.

## Возможности

- Создание книг, глав и карточек с английским словом и переводом.
- Тест по главе или книге: случайный порядок слов, четыре варианта ответа и итоговый процент.
- Экспорт библиотеки в JSON и восстановление из резервной копии. Импорт заменяет текущую библиотеку после подтверждения.
- Импорт резервной копии доступен на телефоне в верхней панели рядом с кнопкой бэкапа.
- Переключение между светлой и тёмной темой с сохранением настройки.
- Возврат к библиотеке по логотипу или ссылке «Библиотека» в верхней панели.

Для теста нужно не менее четырёх карточек в выбранной главе или книге и как минимум четыре разных перевода в библиотеке. Лишние варианты ответа берутся из переводов других карточек библиотеки.
Чтобы закрыть диалог, нажми «Отмена» или кликни за пределами окна.

> Резервные копии хранятся отдельно от браузера. Скачивай их время от времени, чтобы перенести данные на другое устройство или восстановить после очистки данных браузера.
