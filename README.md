# Wordwise

Личный словарь для изучения английского через чтение. Wordwise — статическое веб-приложение: аккаунты пользователей обрабатывает Firebase Authentication, а библиотека каждого пользователя хранится в Cloud Firestore.

Firebase уже настроен для проекта `wordwise-537a9`: включён вход по электронной почте и паролю, создана база Cloud Firestore Standard в регионе `europe-west3`, правила ограничивают доступ данными текущего аккаунта. Проект оставлен на бесплатном плане Spark; проверь актуальные квоты и ограничения перед использованием.

## Настройка Firebase

1. Открой [Firebase Console](https://console.firebase.google.com/) и выбери проект `wordwise-537a9`.
2. Параметры веб-приложения уже находятся в [firebase-config.js](./firebase-config.js). Это публичные параметры Firebase Web App, не пароль и не service-account key. Не добавляй в сайт приватные ключи или service-account JSON.
3. Опубликованные правила можно повторно развернуть из корня проекта командой `firebase deploy --only firestore:rules`. Проект по умолчанию указан в [.firebaserc](./.firebaserc). Команда потребует установленный Firebase CLI и вход в твой Firebase-аккаунт.
4. Размещай сайт на HTTPS-хостинге. Для этой версии домен `tema100kg.github.io` уже добавлен в список разрешённых доменов Firebase Authentication.

Если Firebase-проект или Web App когда-либо пересоздаются, обнови параметры `firebase-config.js`, включи Email/Password, создай Firestore в нужном регионе и обнови домен/правила.

## Вход и хранение

- Можно создать аккаунт или войти по почте и паролю; Firebase поддерживает восстановление пароля по почте.
- После входа библиотека загружается из `users/{uid}/books/{bookId}`. Книги синхронизируются с Firestore, а изменения на другом устройстве появляются автоматически.
- Правила Firestore дают чтение и запись только владельцу, чей `request.auth.uid` совпадает с `{uid}`. Не ослабляй эти правила до публичного чтения/записи.
- Облачная библиотека аккаунта является источником истины и синхронизируется между устройствами.
- Настройка темы остаётся локальной для браузера.

Параметры веб-конфигурации Firebase могут находиться в клиентском коде. Доступ к данным ограничивается Firebase Authentication и правилами Firestore, а не сокрытием `apiKey`.

## Возможности

- Создание книг, глав и карточек с английским словом и переводом.
- Тест по главе или книге: случайный порядок слов, четыре варианта ответа и итоговый процент.
- Синхронизация личной библиотеки с облаком между устройствами.
- Переключение между светлой и тёмной темой с сохранением настройки.
- Возврат к библиотеке по логотипу или ссылке «Библиотека».
- Мобильная компоновка с отключённым масштабированием страницы.
- Установка ярлыка Wordwise на рабочий стол и главный экран с иконкой-тыквой.

## Ярлык приложения

Открой сайт по HTTPS, затем выбери в браузере «Установить приложение» или «Добавить на главный экран». На iPhone и iPad открой сайт в Safari и выбери «Поделиться» → «На экран Домой». Манифест использует иконки `icon-192.png` и `icon-512.png`, а устройства Apple — `apple-touch-icon.png`.

Если ярлык Wordwise уже был добавлен раньше, удали его и добавь сайт на экран заново, чтобы браузер обновил сохранённую иконку.

Для теста нужно не менее четырёх карточек в выбранной главе или книге и как минимум четыре разных перевода в библиотеке.
